# Credit-Score-Prediction-using-Machine-Learning

### 💳 Credit Score Prediction using Machine Learning

I recently worked on a **Credit Score Prediction** project using Python and Machine Learning to analyze customer financial information and classify customers into **Good, Standard, and Poor** credit-score categories.

### 🔍 Project Highlights

* Generated and analyzed **5,000 customer records**
* Performed **data exploration and visualization**
* Analyzed the distribution of **Credit Score categories**
* Studied the relationship between **Outstanding Debt** and Credit Score
* Used **Seaborn & Matplotlib** for visualization
* Prepared the dataset for machine-learning classification
* Explored classification models such as:

  * Logistic Regression
  * Decision Tree
  * Random Forest
  * Gradient Boosting
* Evaluated models using:

  * Accuracy Score
  * Confusion Matrix
  * Classification Report
  * ROC-AUC

### 📈 Key Visualization Insights

The analysis shows that the **Standard** credit-score category has the highest number of customers, while **Poor** customers tend to show higher outstanding-debt values and more extreme debt observations.

### 🛠️ Technologies Used

`Python` • `NumPy` • `Pandas` • `Matplotlib` • `Seaborn` • `Scikit-learn` • `Jupyter Notebook`
